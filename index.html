Preguntas Frecuentes

¿Qué es Home Assistant?

Home Assistant es una plataforma de domótica open source que permite controlar dispositivos inteligentes de forma local, sin depender de nubes externas.

¿Necesito conocimientos de programación?

No es necesario ser programador. Home Assistant tiene una interfaz gráfica intuitive y muchas integraciones preconfiguradas.

¿Cuánto cuesta implementar Home Assistant?

El software es gratuito. Solo necesitas un hardware como Raspberry Pi (50-100€) y dispositivos Zigbee o WiFi compatibles.
