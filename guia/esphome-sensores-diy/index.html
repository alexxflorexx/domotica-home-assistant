Sensores DIY con ESPHome

¿Qué es ESPHome?

ESPHome te permite crear dispositivos IoT personalizados usando microcontroladores ESP32 o ESP8266.

Primer proyecto

Un sensor de temperatura y humedad con ESP32 y DHT22. Necesitas una placa ESP32, un sensor DHT22 y cables jumper.

Integración con Home Assistant

ESPHome detectará automáticamente tu sensor. Solo necesitas agregar el dispositivo desde la interfaz.
