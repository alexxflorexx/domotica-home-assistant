Configuración de Zigbee2MQTT

¿Qué es Zigbee2MQTT?

Zigbee2MQTT permite usar dispositivos Zigbee sin puentes propietarios. Convierte mensajes Zigbee a MQTT que Home Assistant puede entender.

Requisitos

Necesitas un adaptador Zigbee compatible (CC2531, CC2652), Home Assistant funcionando y MQTT instalado.

Instalación

Primero instala Mosquitto broker, luego Zigbee2MQTT y configura el adaptador. Finalmente, empareja tus dispositivos Zigbee.
